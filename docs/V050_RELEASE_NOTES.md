# Pica Library v0.5.0

v0.5.0 是 v0.4.11 之后的一次较大版本收口，重点是升级连续性、双端交互、长任务稳定性和发布工程。

## Windows / Web

- **v0.4.11 可软件内一键升级到 v0.5.0**。正常路径使用来源限定的增量包，不需要手工解压或重装。
- v0.5.0 首次启动后会在用户数据目录的 `runtime-state/upgrade-assistant` 注册经过校验的外置升级 runtime/helper。以后遇到数据库 Schema 跳跃、updater 自身变化或整套程序替换，仍可继续使用网页里的同一个一键更新入口。
- 完整程序更新支持官方 Release / SHA-256 校验、程序树备份、关键用户状态快照、启动/迁移健康检查和失败自动回滚。
- 更新成功后网页自动重新连接和刷新，不再正常停留在“等待重启 / 请手动刷新”。
- 设置中心、书库显示控制、连接状态和新手引导重新整理，减少重复按钮、隐藏状态和多个 DOM owner 争用同一控件的问题。
- E-H 登录/连接状态反馈更明确，本地引擎与可选模块失败不再混成同一个“引擎不可用”。

## Android

- 正式版本提升到 **versionCode 55 / 0.5.0**，保持原包名与正式签名；public v54 已完成原地覆盖安装验收。
- 书库和书架支持长按多选，核心批量操作直接显示在底部 contextual action bar。
- 新增收藏顺序排序，详情页展示已知页数，同一作品检查过程有明确运行状态。
- 普通推荐循环改用有界收藏变化检查，减少反复完整读取收藏夹。
- 推荐批次增加 cycle 级作者曝光控制；详情推荐控制同时提供正向与负向调整。
- 0–10 / BLOCK / Session 等人工调整减少不必要的完整 Catalog 重载，并保留编辑位置。
- 新手引导扩展为任务型流程，覆盖书架、推荐、人工调整、Visual、同步和连接。

## 稳定性与内部改进

- 长任务进度、暂停/继续/取消、恢复和诊断进一步统一。
- Desktop 查询、SQLite 写入、缓存和前端 observer/poller 经过一轮系统硬化。
- Android WorkManager、强杀恢复、内存压力与 UI-thread I/O 路径继续收口。
- 启动/关闭故障隔离、更新回滚和运行时诊断增强。
- 大量性能与真实设备证据工具进入仓库，但未完成的 P1/P2/P3/P4/W5/P6 工作仍继续作为后续项目 backlog。

## 升级

### Windows v0.4.11

推荐：应用内 **设置 → 维护工具 → 软件更新 → 一键检查并更新**。

备用恢复包：

`Pica-Library-v0.5.0-upgrade-assistant-from-v0.4.11.zip`

### Android v54 / 0.4.11

可通过应用内更新通道原地升级到 v55 / 0.5.0。

用户数据与程序文件保持分离。不要为了升级删除 `%LOCALAPPDATA%\Pica Library`，也不要卸载 Android 正式版。
