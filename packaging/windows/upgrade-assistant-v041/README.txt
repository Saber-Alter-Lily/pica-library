Pica Library v0.4.0 -> v0.4.1 Windows 升级助手

推荐入口：
  双击 Upgrade-Pica-Library-v0.4.1.cmd

此助手只接受经过验证的 v0.4.0 -> v0.4.1 升级路径。

它会自动：
1. 下载官方 Pica-Library-v0.4.1-windows-x64.zip；
2. 校验固定 SHA-256 与目标 SOURCE_SHA；
3. 识别或要求选择旧版 v0.4.0 程序目录；
4. 检查漫画库/下载目录是否错误地位于程序目录内部；
5. 关闭旧版；
6. 在 %LOCALAPPDATA%\Pica Library Upgrade Backups 建立配置与 SQLite 安全快照；
7. 将旧程序目录整体改名为备份，再复制 v0.4.1 程序文件；
8. 启动 v0.4.1 并验证版本与数据库 schema；
9. 若健康检查失败，自动恢复旧程序和升级前数据快照。

不会把 %LOCALAPPDATA%\Pica Library 当作程序目录删除或覆盖。
不需要卸载旧版，也不需要重新导入漫画库。

如果你的漫画保存目录位于旧程序文件夹内部，助手会停止自动升级，并提示你先迁移数据目录。

升级成功后请先保留旧程序备份和安全快照一段时间，确认正常使用后再手动清理。
