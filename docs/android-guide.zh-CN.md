# Pica Library Android 使用说明

> 当前正式版本：**v0.4.8 · versionCode 50**。Android 版本未上架任何应用商店，请仅从本仓库正式 GitHub Release 下载 APK。

## 1. 下载与安装

1. 打开 [GitHub Releases](https://github.com/Saber-Alter-Lily/pica-library/releases/latest)。
2. 下载当前版本 APK；v0.4.8 对应 `Pica-Library-Android-v51.apk`。
3. 在手机上打开 APK，并按 Android 系统提示允许本次安装。
4. 首次启动后阅读并确认使用说明，再进入应用。

不要从不明网盘、群文件或第三方下载站获取 APK。正式更新会校验版本、包名、SHA-256 和官方签名身份。

## 2. 底部四个主入口

当前主导航固定为：

- **书库**：查看统一漫画库、本地内容、收藏、书架、阅读历史和已下载内容。
- **推荐**：运行手机端独立推荐、切换批次并查看推荐依据。
- **在线**：访问 Pica、E-Hentai / ExHentai 的在线搜索、分类、排行、收藏和阅读能力。
- **设置**：管理连接、推荐与画风、账号、外观、存储、软件更新、支持项目和关于信息。

## 3. 在线来源与账号

### Pica

支持登录、注册、搜索、分类、排行、收藏同步、在线阅读和下载。注册资料由你自行填写并确认后提交给第三方 Pica；提交注册不会自动登录、同步或下载。

网络超时不等于密码错误。Pica 在线服务不可用时，本地、局域网和 WebDAV 阅读仍可继续使用。

### E-Hentai / ExHentai

E-Hentai 提供搜索、详情、在线阅读、下载和收藏等能力。ExHentai 是 E-H 账号下的可选扩展；不可访问时不会阻塞 E-H、本地书库或推荐。

## 4. 推荐与人工调整

Android 可以独立运行推荐，不要求 Desktop 持续在线。

进入 **设置 → 推荐与画风** 可以：

- 查看推荐画像；
- 打开 **人工调整**；
- 对标签、作者等兴趣项设置 **0–10 档**；
- 设置屏蔽、减少推荐或“本次想看”；
- 开启或关闭反馈原因；
- 管理画风推荐；
- 与 Desktop 比较并同步可移植推荐偏好。

**5/10 是中性起点。** 即使当前没有收藏夹画像，也可以先手动配置推荐参数。

画风推荐可以单独关闭，不会影响常规推荐。

## 5. 连接 Desktop

手机和电脑在同一局域网时：

1. Desktop 打开 **设置 → 连接与同步**，启用移动端连接。
2. Android 打开 **设置 → 管理连接**。
3. 使用显示的配对信息完成连接。

配对成功后，Android 可以：

- 直接读取 Desktop 本地漫画和封面；
- 直接阅读 Desktop 已下载漫画；
- 同步可移植书库与推荐基础数据；
- 比较并合并两端的人工推荐调整；
- 接收 Desktop 上已有的主题包。

配对完成后，推荐和书架等后续同步会在后台继续进行，不会把同步耗时误显示成“仍在配对”。

## 6. WebDAV

WebDAV 可以作为 Desktop 离线时的备用阅读来源。可以在设置中查看、切换和使用已经配置的远程存储。

当 Desktop 在线时，局域网本地读取通常优先；Desktop 不在线时可以回退到 WebDAV。

## 7. 阅读与下载

Android 支持：

- 手机本地漫画；
- Desktop 已下载漫画；
- WebDAV；
- Pica 在线阅读；
- E-H 在线阅读。

阅读器支持左到右、右到左、纵向连续阅读、章节切换、进度保存和续读。

Android 也可以本地下载漫画。下载队列支持进度显示、失败恢复以及暂停 / 继续。

## 8. 外观与主题

在设置中可以选择基础明暗模式，也可以使用 `.pica-theme` 主题包。

主题包可以从 Desktop 同步到 Android，但当前启用主题由手机自己保存，不会强制跟 Desktop 一致。

## 9. 软件更新

进入 **设置 → 软件更新** 检查正式版本。

正式更新会检查：

- versionCode / versionName；
- APK SHA-256；
- 应用包名；
- 官方签名身份。

已有 **v42 / 0.4.0** 的普通用户可直接通过应用内更新链原地升级到 **v51 / 0.4.7**，无需安装任何中间版本。

如果下载更新时短暂显示等待系统下载服务，通常是 Android DownloadManager 正在排队；可以稍后继续或重新开始任务。

## 10. 支持项目

进入 **设置 → 支持项目** 可以看到：

- **爱发电**：自愿支持后续开发、测试和维护；
- **GitHub 项目主页**：Star、反馈问题或参与开发。

赞助完全自愿，不会解锁额外功能、内容、下载权限或访问权限，也不会影响免费版本的完整使用。

## 11. 数据与使用边界

- Pica Library 是开源、本地优先的个人数字内容管理工具。
- Android 敏感会话使用 Android Keystore 保护。
- 项目不销售、托管或重新分发漫画内容。
- 用户需要自行确保账号使用、访问、下载、保存和阅读符合所在地法律法规、平台条款与授权范围。
