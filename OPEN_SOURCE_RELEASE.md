# Open-source release status

Pica Library has returned to a current-source open-source model starting with Alpha8.6 / Desktop v0.3.4.

The repository contains the application source used for the official feature set. Official Android binaries remain signed with the project's fixed Preview signing identity. Private signing keys, credentials, payment secrets and release automation secrets are never part of the source tree.

Personalization is a community Star reward in official builds. The verification implementation is intentionally visible in source; forks may change it under the repository license.
