# Pica Library 0.2.0-dev.2 本地用户验收指南

这不是公开发布版。请把 dev.2 ZIP 解压到新的空目录；不要覆盖现有正式目录。更新测试只使用提供的 dev.1 全量包与 dev.2 Update ZIP，并先备份真实数据。

## A. 快速更新收藏

1. 记录当前“Pica 收藏”数量，在 Pica 端新增一部收藏。
2. 点击“更新收藏”。观察“已检查第 N 页、发现新增 N 部”和耗时。
3. 正常情况下应只检查第 1 页或很少页，不应扫描全部收藏页。
4. 如果页面结构、数量或稳定重叠异常，界面应明确显示正在转为完整校验。

## B. 完整校验收藏

点击“完整校验收藏”一次。等待所有页完成，确认最终 Pica 收藏数量与远端一致，远端已取消收藏的旧项目被正确更新；其他本地漫画记录不应被删除。

## C. 漫画库计数与范围

依次打开“漫画库”“Pica 收藏”“已下载”“全部缓存记录”。推荐、搜索或详情浏览产生的纯缓存记录只能出现在“全部缓存记录”；只有被收藏、加入书架、实际下载或显式导入后才能进入普通漫画库。生成新推荐后，漫画库计数不应无故增加。

## D. 推荐缓存与自动准备

启动应用后直接进入“发现”，不要点击“查看推荐”。预期已有推荐，或显示“正在准备推荐”。离开再返回、刷新浏览器、退出并重启应用，当前 Session 与批次应恢复。进入第 2 批后应显示“下一轮已准备好”或“正在准备下一轮”。

## E. 下一推荐 Session

依次浏览 1/5 至 5/5。5/5 后点击“换一批”，新 Session 应立即出现；核对没有与此前 Session 完全相同的漫画 ID/作品。普通刷新不得清除 seen 历史；只有确认“重新开始推荐”才创建新 cycle。

## F. Reader

从“已下载”、书架或漫画库进入一个已下载章节，读到中间页，点击“← 退出阅读”。应回到进入 Reader 前的页面。重新打开应恢复同一章节和页码；再用浏览器刷新及应用重启各验证一次。切换章节前后的进度也应保留。

## G. 书架

打开含漫画的书架，检查封面、网格/列表、小/中/大以及“加载封面”开关。关闭封面后滚动不应发起新的封面请求；选择、移出、阅读和下载操作仍应可用。

## H. ZIP 与 CBZ

Reader 中优先点击“导出 ZIP”。用常见压缩软件或阅读器打开，确认文件名为 `001.jpg`、`002.jpg` 等有序图片，且归档中没有账号、密码、token、Cookie、数据库或绝对路径。可再导出 CBZ，确认页集合与 ZIP 相同。

## dev.1 → dev.2 更新链

1. 新目录解压并启动 `Pica-Library-v0.2.0-dev.1-local-test-windows-x64.zip`。
2. 创建一个无害书架并记录阅读位置。
3. 设置 → 更新，拖入 `Pica-Library-v0.2.0-dev.2-local-update.zip`。
4. 核对版本、SOURCE_SHA、文件数与 database schema 7，点击“更新并重启”。
5. 确认版本为 dev.2，收藏、catalog、书架、阅读进度、推荐 Session、下载和设置均保留。

问题报告请只附脱敏步骤、页面、版本和合成截图；不要发送账号、密码、token、Cookie 或代理凭据。
