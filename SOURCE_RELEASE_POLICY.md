# Delayed source release policy

Pica Library began as an open-source project. To balance transparent security review with sustainable original development, new project-authored source now follows a delayed-release model.

1. Official binaries remain free to use.
2. Current development source is private during the active development window.
3. The normal target for publishing a source snapshot is after roughly 90 days and at least two subsequent feature releases; security, legal or third-party constraints may require a longer delay.
4. When a delayed project-authored snapshot is released, the current intention is to use AGPL-3.0-or-later unless a component requires another compatible license.
5. Source already released under MIT or another license keeps that license permanently; later policy changes do not revoke prior grants.
6. Official branding, signing keys and private entitlement-signing keys are never included in source releases.

This policy is prospective. Transition-era Alpha8.3/v26 development occurred while source was still publicly visible, so copies may continue to exist in Git history, caches or forks.
