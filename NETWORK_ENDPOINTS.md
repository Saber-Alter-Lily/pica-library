# Network endpoints

Expected network destinations include:

- Pica API: `https://picaapi.picacomic.com/`
- Pica media/CDN URLs returned by the Pica API
- Official updates: GitHub Releases under `Saber-Alter-Lily/pica-library`
- Desktop LAN bridge: the local host explicitly paired by the user
- WebDAV: the endpoint explicitly configured by the user

Theme packs are data-only archives. Their accepted contents are constrained to JSON configuration and PNG/JPEG/WebP assets; executable code, scripts and arbitrary HTML are not accepted by the theme-pack validator.
