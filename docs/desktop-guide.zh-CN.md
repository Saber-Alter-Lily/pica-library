# Pica Library Desktop / Web 使用说明

> 适用于 Windows Desktop / 本地 Web UI。当前正式版本：**v0.3.11 / Alpha8.11**。

![Desktop / Web 页面说明](assets/desktop-overview.webp)

## 1. 安装与启动

1. 从 [v0.3.11 Release](https://github.com/Saber-Alter-Lily/pica-library/releases/tag/v0.3.11) 下载 `Pica-Library-v0.3.11-windows-x64.zip`。
2. 完整解压后运行 `Pica Library.exe`，不要直接在压缩包内运行。
3. 首次启动会显示使用提示；确认后进入本地 Web UI。
4. 根据需要填写 Pica 账号、代理和漫画保存目录。

Pica Library 默认在本机运行，本地 Web UI 仅用于操作桌面程序本身。

## 2. 主要页面

- **首页**：常用入口、状态与近期内容。
- **漫画库**：集中浏览已同步的收藏与本地漫画，可搜索并按作者、标签、分类等筛选。
- **书架**：把漫画按自己的方式分组管理。
- **发现**：浏览推荐与在线发现内容。
- **我的收藏图鉴**：从收藏数据中整理和查看个人收藏画像。
- **下载任务**：查看进行中、等待、失败任务；已结束任务默认收起，需要时可重新显示。
- **已下载**：集中管理已经落地到本机的漫画，并进入阅读。
- **设置**：账号、连接、外观、存储、维护和更新统一在这里管理。

## 3. 下载与本地阅读

下载任务采用持久化队列。程序重启后仍会保留任务状态；失败任务可继续处理，已完成和已取消任务默认折叠，避免长期占据主列表。

已下载内容进入 **已下载** 页面统一管理。Android 与电脑配对后，可以直接读取电脑已经下载的漫画，不需要在手机上再次下载同一份内容。

## 4. 设置中心

设置中心分为：

- **基本设置**：账号、下载目录和基础参数。
- **连接与同步**：Android 配对、远程访问与 WebDAV。
- **外观与个性化**：明暗模式与主题包。
- **下载与存储**：下载任务入口、缓存与存储相关操作。
- **维护工具**：库维护、修复、作者数据等工具。
- **软件更新**：检查、下载、校验、应用更新并重启。

## 5. Android 配对

电脑与手机位于同一局域网时，在 Desktop 的连接设置中开启移动端连接并获取配对信息；手机端进入 **连接 → 管理连接** 完成配对。

配对后手机可以：

- 读取电脑端本地漫画和封面；
- 访问电脑已下载的内容；
- 同步部分状态与主题包；
- 在电脑在线时使用局域网高速读取。

WebDAV 可以作为电脑不在线时的备用来源。

## 6. 个性化装扮

Desktop 支持导入 `.pica-theme` 主题包，并把可用主题包同步到 Android。若某项主题功能需要额外验证，请按应用内提示完成。Desktop 与 Android 各自保存当前启用主题，不强制保持一致。

## 7. 软件更新

优先使用 **设置 → 软件更新**。

v0.3.11 的正式增量包已经逐一验证支持：

`v0.3.0 / v0.3.1 / ... / v0.3.10 → v0.3.11`

更新过程会校验包来源和文件完整性，并保留用户数据库、下载内容与本地配置。若非常旧的客户端所在网络无法访问 GitHub 更新通道，可改用完整 ZIP 覆盖应用程序目录，用户数据仍应保留在独立数据目录中。

## 8. 数据与安全

- Pica Library 是本地优先的个人数字内容管理工具。
- 项目不销售、托管或重新分发漫画内容。
- Windows 凭据使用当前 Windows 用户的 DPAPI 保护。
- 官方发布同时提供 SHA-256 与构建透明度信息。
- Android 官方 Preview 使用固定签名证书校验。
