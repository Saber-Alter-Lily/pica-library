# Pica Library Desktop / Web 使用说明

> 适用于 Windows Desktop / 本地 Web UI。当前正式版本：**v0.4.6**。

## 1. 安装与启动

1. 从 [GitHub Releases](https://github.com/Saber-Alter-Lily/pica-library/releases/latest) 下载当前稳定版 Windows 完整包；v0.4.6 对应 `Pica-Library-v0.4.6-windows-x64.zip`。
2. 完整解压到普通文件夹后运行 `Pica Library.exe`，不要直接在压缩包内运行。
3. 首次启动会打开本地 Web UI，并进入首次设置。
4. 按需配置账号、漫画保存目录、下载方式与 HTTP/HTTPS 代理。

Pica Library 默认在本机运行。Desktop 程序负责本地服务、数据、下载与更新；浏览器页面只是它的本地操作界面。

## 2. 主要页面

- **首页**：查看常用入口、状态和近期内容。
- **漫画库**：统一浏览 Pica、E-H、本地下载、Desktop、Android 与 WebDAV 相关漫画记录，并按标题、作者、标签、分类、Provider、存储位置等筛选。
- **书架**：按自己的方式组织漫画。
- **推荐 / 发现**：浏览个性化推荐与在线发现内容。
- **在线**：访问 Pica、E-Hentai / ExHentai 搜索、分类、排行、收藏等在线能力。
- **阅读历史**：按漫画查看最近阅读，并恢复到具体章节与页码。
- **下载任务 / 已下载**：管理下载队列、失败重试、暂停继续和本机已下载内容。
- **设置**：统一管理推荐、连接、外观、存储、维护和软件更新。

## 3. 在线来源与账号

### Pica

支持登录、注册、搜索、分类、排行、收藏同步、在线阅读与下载。注册入口只负责提交你确认后的资料，不会自动登录、同步或下载。

### E-Hentai / ExHentai

E-Hentai 支持公开搜索、详情、在线阅读、下载、Latest、Popular、Favorites、Watched、Toplists 和高级筛选。ExHentai 是 E-H 账号下的可选扩展；不可访问时不会阻塞 E-H、本地书库或推荐。

E-H 标签保留原生 `namespace:value` 身份，中文显示和搜索辅助由翻译层提供，不会把中文显示名写回为 canonical tag。

## 4. 推荐与人工调整

推荐同时使用长期兴趣、最近行为、显式偏好和当前会话意图。Pica 与 E-H 分别召回候选，再统一排序、去重和分批展示。

在 **设置 → 推荐与画风** 中可以：

- 查看推荐画像；
- 对标签、作者等兴趣项进行 **0–10 档**人工调整；
- 设为屏蔽或降低推荐；
- 设置“本次想看”等会话意图；
- 开启或关闭画风推荐；
- 查看和管理与 Android 之间的推荐同步。

**5/10 是中性起点。** 即使新用户还没有足够收藏数据，也可以先手动配置初始偏好，不需要等待系统先生成收藏画像。

画风推荐是独立模块。关闭后只停止画风相关信号，不影响常规推荐。

## 5. 下载、阅读与历史

下载任务采用持久化队列。程序重启后仍会保留任务状态；失败任务可重试，任务可暂停或继续。

支持：

- Desktop 本地已下载阅读；
- Pica 在线阅读；
- E-H 在线阅读；
- WebDAV 远程读取；
- 左到右、右到左、纵向连续阅读；
- 章节切换、进度保存和续读。

Android 与 Desktop 配对后，可以直接读取电脑已经下载的漫画，不需要在手机上重复下载同一份内容。

## 6. 设置中心

当前 Desktop Settings Hub 分为七个区域：

### 基本设置

放置账号、基础参数以及 **支持项目**。支持项目提供爱发电与 GitHub 入口；赞助完全自愿，不会解锁额外功能、内容或访问权限。

### 推荐与画风

管理推荐画像、0–10 人工偏好、显式反馈、推荐同步、画风模块和相关高级诊断。

### 连接与同步

管理 Android 配对、跨端同步、远程访问和 WebDAV。

### 外观与个性化

管理明暗模式、主题包和个性化外观。Desktop 与 Android 可以同步主题包，但当前启用主题彼此独立。

### 下载与存储

管理漫画保存目录、缓存、下载任务和存储策略。

### 维护工具

提供库维护、修复、日志、导出以及其他高级维护入口。

### 软件更新

检查官方 Release、下载并校验兼容更新、导入本地更新 ZIP、应用更新、重启和必要时回滚。

## 7. Android 配对与跨端同步

电脑与手机位于同一局域网时，在 Desktop 的 **设置 → 连接与同步** 中开启移动端连接并获取配对信息；Android 在 **设置 → 管理连接** 中完成配对。

配对后可以：

- Android 直接读取 Desktop 本地漫画和封面；
- Android 直接读取 Desktop 已下载内容；
- 共享可移植书库与推荐基础数据；
- 比较并同步两端的显式推荐偏好；
- 同步可用主题包；
- 在局域网内优先高速读取 Desktop 内容。

两端推荐可以各自独立运行。同步不会强制让两端当前推荐批次或 Session 完全一致。

WebDAV 可以作为 Desktop 不在线时的备用来源。

## 8. 个性化装扮

Desktop 支持创建、导入和管理 `.pica-theme` 主题包，并可把主题包同步到 Android。主题包只包含受控数据和图片资源，不执行任意脚本。

Desktop 与 Android 各自保存当前启用主题，不要求两端显示完全一致。

## 9. 软件更新

优先使用 **设置 → 软件更新**。

面向普通用户的公开升级路径只有一条：

- **v0.4.0 → 当前最新版 v0.4.6**：使用 v0.4.6 Release 中的 `Pica-Library-v0.4.6-upgrade-assistant.zip` 一次直达，无需安装任何中间版本。

升级助手会校验官方完整包、保护 `%LOCALAPPDATA%\Pica Library`、建立程序和数据库安全快照、替换程序并执行健康检查；失败时自动回滚。

应用程序文件与用户数据目录彼此分离。不要删除 `%LOCALAPPDATA%\Pica Library`。如漫画保存目录被放在旧程序目录内部，升级助手会阻止自动替换并提示先迁移数据。

## 10. 数据与安全

- Pica Library 是本地优先的个人数字内容管理工具。
- 项目不销售、托管或重新分发漫画内容。
- Windows 敏感凭据使用当前 Windows 用户的 DPAPI 保护。
- 官方 Release 提供 SHA-256 与构建透明度信息。
- 数据库、书架、阅读历史、设置和下载内容默认与程序目录分离。
- 只应下载和保存自己有权访问的内容。
