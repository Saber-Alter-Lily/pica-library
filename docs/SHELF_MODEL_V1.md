# Shelf Model v1

书架是本地整理结构，与远端“Pica 收藏”完全不同。漫画可同时属于多个书架；同一漫画不能在同一书架重复。名称会 trim，空名和不区分大小写的重名被拒绝。

删除书架只级联删除 `shelf_items`，不会删除漫画记录、Pica 收藏、下载任务或文件。列表、推荐、搜索和书架内容共享选择语义；搜索结果加入时可安全 upsert 最小 canonical 元数据。

“将全部筛选结果加入书架”由 `LibraryQueryService` 在后端重放同一查询，使用全部匹配 ID，不受当前 DOM 48 项限制；确认框显示后端结果数。

本版本只支持一次性批量加入，不实现自动规则或 Smart Shelf。未来规则必须作为单独能力加入，不能改变手工成员的本地语义。
