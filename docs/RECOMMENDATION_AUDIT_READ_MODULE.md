## Export and privacy boundary

The Save choice now precedes data reads/evaluation. Cancel or picker failure acquires no read callback and writes no file. After confirmation, the existing read order/limits and eleven ZIP entries are preserved, including active app-session binding. A serialization failure precedes output write; write failure is not reported as success. Atomic recovery from arbitrary disk/full/interrupted writes is not claimed.

Credential stores/configuration and downloaded bodies are not export capabilities; the catalog explicitly selects its original minimal fields. Raw user events, private labels, policy and audit evidence are intentionally retained for the user's requested analysis. This is **not anonymization or a general sanitizer for arbitrary secret text a user may have placed in those records**. Sharing a real export still requires the user's explicit choice; no real export is collected for this development pass.
