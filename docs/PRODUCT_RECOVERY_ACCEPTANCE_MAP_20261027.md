## 执行与权责

1. 原 42 项继续沿用原文验收标准；如用户报告了新失败，即使既有工程测试为 PASS，用户验收仍是 NOT_ACCEPTED。
2. 新项围绕实际退步、新模块维护边界和“来源真实外置”；不得把 Android 高级纯文字目录、关闭来源默认开关、核心 Windows 不携带 JVM、合成第二 sourceId 当作对应功能完成。
3. 对每个案例更新：源 SHA，Windows/Android 的适用范围，单元/CI 与物理设备结果，证据链接和未验证缺口。适配器无某能力时须显示不支持；已承诺功能不能被 N/A 跳过。
4. G1=NEW-UI 全部真实视觉/设备验收与旧 UX 等有关案例；G2=NEW-MOD/NEW-SRC 及 SRC/CORE 适用项；G3=UPD 与 NEW-DATA/NEW-PERF；G4=DEL/全项目阻断清零、用户批准。每个 Gate 和发布需分别得到许可。
