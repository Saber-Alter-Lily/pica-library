# 日常使用入门

这份指南只介绍日常使用。账号、画风、跨端同步和诊断见[高级功能指南](ADVANCED_FEATURES_GUIDE.zh-CN.md)。软件内也有两套独立入口：**设置 → 帮助与新手引导**。日常引导不会接着自动进入高级教程。

首次打开可选择“只配置本地书库”：确认保存目录即可，不需要 Pica、E-H 或 JM 账号。软件不附带漫画内容，外部来源可以稍后再连接。这个入口不会替你登录、同步或生成在线推荐，也不会删除已有来源凭据。

未发布候选版支持直接导入自己的漫画，无需来源账号：Desktop **漫画库 → 导入漫画文件夹 / 导入 CBZ**；Android **书库 → 导入本地漫画**，通过系统选择器选一个文件夹或 CBZ/ZIP。两端都是先预览，再确认复制，保留原文件；子文件夹作为章节，文件名按数字排序。从同一设备的同一原始位置重新导入可沿用原作品身份与进度。仅支持 JPG/PNG/GIF/WebP 正文；CBR/PDF/EPUB 和自动扫描尚未加入。见 [Desktop 边界](LOCAL_CONTENT_INGESTION.md) / [Android 边界](NATIVE_LOCAL_CONTENT_INGESTION.md)。

Android 已导入的作品可从导入列表，或 **详情 → 来源与副本 → 导出正文为 CBZ** 保存到自己选择的位置。它只带漫画图片，不带阅读历史、书架或私人标签；重新导入这个新文件不会恢复旧身份和整理数据。取消或失败可能留下空文件/半成品，确认导出文件可正常阅读前不要删除唯一副本。它不是完整数据备份，更新仍应覆盖安装，不要先卸载。

## 1. 找到一本漫画

已有书库时，直接搜索标题或作者，打开作品详情即可。不需要每次先同步收藏、生成推荐或建立画风索引。

- 漫画库：查看已经整理进来的作品。
- 书架：按自己的方式归类，不等于修改网站上的收藏。
- 在线搜索：从已连接且当前可用的来源找新作品。
- 已下载：查看设备上的可用下载。只有远程或电脑副本时，还需要相应连接。

没有结果先检查来源和筛选条件；不要为此清空数据库。

## 2. 打开阅读，知道怎样回来

从作品详情或已下载列表选择当前可用的阅读方式。Web 阅读器顶部有退出和章节切换；键盘 Esc 可退出。Android 阅读器使用屏幕上的控制与系统返回。

本地、LAN、WebDAV 和在线来源是不同路径。电脑离线后，依赖电脑的 LAN 内容不可读；手机已有完整本地下载则无需电脑。

只有你已经自行运行外部宿主时，才需要高级指南中的实验性“宿主书库”路径；它是另外授权的 Desktop 短期会话，不会因完成诊断而自动接通，也不是手机通用来源或本地导入。普通本地阅读无需配置它。

## 3. 想看新内容时再打开推荐

已有推荐可以直接查看、换一批，不需要每次重新生成整个周期。

- 喜欢：提供正向反馈。
- 不喜欢：提供负向偏好反馈，不等于永久屏蔽。
- 屏蔽：明确排除对应目标，注意是作品、作者还是标签。
- 调整推荐：只有判断不合口味时才需要进入，不要求先把全部滑杆设置一遍。

收藏一本漫画不代表明确喜欢它的每个标签。偏好更改的生效范围与重算状态以界面提示为准，不把旧批次当成已经重算的新结果。

## 4. 下载与重试

先选择作品或章节，再在任务页面看等待、进行、失败和完成状态。失败先看原因，再重试。

暂停/取消任务、移出书架、取消收藏、删除本地文件和删除网盘副本是不同操作。执行删除前核对目标，尤其不要把“清理应用文件”理解为“清空全部数据”。

## 5. 推荐不准、连接失败时

只处理与问题相关的一项：推荐不准看偏好，连接失败看对应来源/设备，下载失败看任务原因。没有向量或标签时表示未知，不是你不喜欢。

不用先运行 Shadow、Visual QC、评估、全库索引或完整重建。需要这些功能时，再从高级指南选择章节。

## 引导的约定

- 可以跳过、重看；Web 会保存独立的步骤位置，Android 日常版可从帮助重新开始。
- 已看过旧版混合教程的用户不会被强制重复自动提示。
- 关闭自动提示不影响手动打开两套指南。
- 高级章节“已读”只代表看过说明，不代表配置或连接成功。
- 引导不会替你登录、同步、下载、删除、更新或切换画风模式。

## 可选：只让你关心的标签参与推荐

未发布候选中的“用于推荐的标签与私人标签”默认全开，不需要新用户先配置。想精简时可以全关，再按分类及收藏涉及数量挑选；关闭标签不隐藏漫画，也不能绕过屏蔽。

更改先暂存。Desktop 可保存后按需重新生成推荐；重建成功前仍保留旧批次。手机保存后仅重排现有缓存，重新召回需要另外生成；同步到电脑也需要你确认。私人标签和映射的细节见高级指南，日常阅读不必使用。画风参考集及自动细粒度画风补标仍未提供。
