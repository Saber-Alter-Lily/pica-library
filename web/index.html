第一次使用

  1. Fork 项目到自己的 GitHub 账号。
  2. 在 Fork 的 Actions Secrets 设置 PICA_ACCOUNT 和 PICA_PASSWORD。
  3. 运行 prepare-library，下载生成的数据包。
  4. 回到这里导入 pica-library-bundle.json。
Fork 项目 打开准备工作流

本地完整版

  1. 下载或克隆项目。
  2. 运行 powershell -ExecutionPolicy Bypass -File scripts/setup-windows.ps1
  3. 在 .env.local 填写账号，再运行 node dist/library-cli.js serve
