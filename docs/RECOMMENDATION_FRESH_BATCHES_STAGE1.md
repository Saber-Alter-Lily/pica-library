# 推荐换批与作者轮换 · 本地候选

从正式标签 `v0.5.0`（`bec7f9f31828e8c57e0a2c103b6b1206c22c37cf`）独立开发。不是安装包或发布公告。未使用已封存开发线的代码，未改变正式数据、数据库结构、画风状态、原排序模型或搜索预算。

## 使用时的变化

- 网页推荐页处于前台且至少一张真实卡片露出时，记录当时这一批渲染出的作品 ID；这不等于每张卡片都看过。单张卡片曝光仍是独立事件。首页预加载、后台生成、弹窗完全遮挡、状态查询以及手机预取均不作为展示。
- 最近 10 个不同的已确认批次共用一个窗口，换批和重新生成不重置它；同一轮仍不重复发已分配作品。同一持久化批次无论重复报告多少次都只记一次，过期的旧标签页也不会把它挪回窗口。升级初始为空：不把旧版本仅有的分配记录追认为人看过。
- 默认每批同一位可识别作者最多 2 席，连续三批合计最多 4 席。只有新作品不足以同时满足这些作者限制时才放宽作者限制，且在批次证据中记下让位次数。不放宽近期作品去重、收藏/已有作品过滤或明确屏蔽；不够 12 本就显示实际数量。
- 3 个作者检索位不变。按画像可信度和收藏支持选出前 8 位和接下来的 16 位；前一组轮换 2 位，后一组轮换 1 位。优先最近 3 个搜索计划用得少的作者，其次看留存计划内的使用次数（最多 50 个）。小画像不虚构作者，也不重复一个身份。检索次数不是展示席位数。

## 离线验收

用一组已有的连续 10 轮真实首批记录、共 2,580 个候选位置。只读事务打开 SQLite；没有在线重新生成，没有把这十轮写成用户事件。脚本加载本仓库正式标签里的原分配器，并逐位置核对每批 12 本的顺序（10/10 全匹配）。新分配器使用相同的固化候选，从空展示历史开始，每轮只将自己选出的首批作为下一轮的历史。

| 指标 | 正式版 | 本地候选 |
|---|---:|---:|
| 十轮总席位 | 120 | 120 |
| 不同作品 ID（不是跨来源同作品识别） | 49 | 120 |
| 不同且可可靠归属的作者 | 32 | 86 |
| 占位最多的一位作者 | 30 | 14 |
| 入选作品在原排名的平均位置 | 24.49 | 49.49 |
| 十轮作者搜索计划中的不同作者 | 3 | 18 |

正式版每轮首次出现的作品数：`12,12,12,0,3,4,0,5,1,0`；新方案每轮均为 12。新方案没有一次因为候选不够而放宽作者限制。32/86 采用同一口径，排除匿名、多人合署等不能可靠归为一个人的记录；不同于早期设计演算里较宽的作者口径及历史预热方式。

| 门禁 | 范围 |
|---|---|
| 自动测试 | 全量 224 个测试文件，1,199 项通过、1 项跳过；新增用例覆盖近十批、作者上限、候选不足、缓存重读、重启、无效/重复回执、轮换、屏蔽即时生效及真实本机 HTTP 处理。既有代理发现测试会读取进程代理环境；全量回归只在测试子进程屏蔽 HTTP(S)/ALL_PROXY，不修改系统或应用代理。 |
| 浏览器 | 在临时配置的无界面 Edge 上运行实际网页，拦截全部请求并返回合成数据。首页渲染和全屏遮挡均不产生回执；进入推荐、再返回只产生第一次回执；换一批产生第二个不同回执。没有页面异常。 |
| 构建 | TypeScript、Web 语法检查与正式工程构建均通过；未制作或部署 Windows/Android 安装包。 |

独立复核：从上面的完整基线应用改动，`pnpm install --frozen-lockfile`，运行 `pnpm type:check`、`pnpm web:check`、`pnpm test`、`pnpm build`。离线浏览器夹具是 `scripts/benchmark/recommendation-visible-browser.mjs`，可显式指定 `PICA_PLAYWRIGHT_MODULE` 和 `PICA_BROWSER_EXECUTABLE`。只读回放为 `pnpm exec tsx scripts/benchmark/recommendation-freshness-replay.ts <数据库路径> <按时间排列的10个cycleId>`；只输出聚合数，需保留上面基线 Git 对象。真实库、标识清单、账号资料、漫画标题、作者名单均不随审阅材料提供。

## 尚未验收

这组数据能验证不重复，不能证明更合口味；平均取书名次更靠后，恰是需要检查的代价。作者轮换只证明“会搜索不同作者”，不证明新搜索能返回喜欢的书。新版没有增加“陌生作者发现位”，没有把手机独立离线浏览算成桌面已展示，也没有做 Android 真机验收。

下一门禁：先用作品自身的系列/题材元数据验证“为什么给你推荐这位新作者”；再用不同于这十轮的数据，在隔离影子环境对比新旧召回，记录符合条件的发现作者数、请求预算与等待时间。不填虚构标签、不挤两个凑数的位置。达到供应和性能门禁后才进行主观盲评，是否发布另行决定。
