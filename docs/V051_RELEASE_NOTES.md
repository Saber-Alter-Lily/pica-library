# Pica Library v0.5.1 · 订阅更新与日常阅读

**适用：Windows/Web v0.5.0 → v0.5.1，Android 正式版 v55 → v56。**

- **订阅区放在书库里。** 搜索下方有筛选、排序、订阅更新。打开作品详情订阅作者后，从「全部更新」看作品封面，或切换到某位作者。旧作品不会因为首次订阅就堆满收件箱。打开最早待看的更新章、或手动标记该章才清掉对应提醒；点封面进详情本身不标记。
- **随机排序由你控制。** 重排不改变收藏或书架，普通重绘与翻页不会自己洗牌。
- **翻页不等于重新生成。** 一轮最多六页，每页最多十二本；候选充足时按熟作者与陌生作者混搭。见过的作品、已订阅作者不占新的推荐位置，候选不足不硬凑。普通点赞不会立即打乱当前轮次。
- **手机更好点。** 推荐仍是单列，喜欢、不喜欢、看过、更多用图标；订阅区采用书架布局，多章作品突出当前分段。优化窄屏按钮、长设置状态及旧详情页的深色对比。
- **电脑保留宽屏操作。** 键盘可聚焦工具栏，模态订阅书架支持 Esc 关闭；保留升级结束后的网页重连修复。

### 更新与数据

Windows v0.5.0：打开 **设置 → 维护工具 → 软件更新 → 一键检查并更新**，确认后由应用下载增量包、替换程序并重新启动，不用解压 ZIP 或手动迁移数据。完整包和升级助手仅作备用。
Android 正式 v55：在 **连接 → 软件更新** 检查、下载并更新，再确认 Android 系统安装弹窗；不要先卸载。MuMu Dev 包不是正式 OTA 安装包。本次不要求重新导入书库、重建画风索引或重新登录，不修改数据库 schema。

订阅只依据能核实的来源记录；连接失败、缺少章节数量或只查到部分作者时，不会把未查到的内容标为已读。电脑和手机订阅按设备保存，本版不宣称跨设备同步未读。真实第三方登录、网盘和真机相机不属于本次布局验收。
