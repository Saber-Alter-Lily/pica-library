# Pica Library 0.2.0-dev.1 本地用户验收指南

这不是公开发布版。请只使用本次提供的三个 ZIP，在新目录中测试；不要覆盖现有正式目录。先备份真实数据。首次远端收藏测试只操作一部漫画。

## A. dev.0 → dev.1 更新

1. 解压 `Pica-Library-v0.2.0-dev.0-update-base-windows-x64.zip` 到新目录并启动。
2. 新建一个无害测试书架或设置，记住内容。
3. 打开“设置 → 更新”，拖入 `Pica-Library-v0.2.0-dev.1-local-update.zip`。
4. 核对目标版本、SHA、文件数和数据库 schema；点击“更新并重启”。
5. 确认自动重启为 `0.2.0-dev.1`，书架、设置和数据仍在，且无需手工替换文件。

## B. 筛选与书架

在“Pica 收藏”scope 检查作者/标签建议、计数、输入筛选、标签全部/任一、chips、结果数与清除。创建“测试书架 A/B”，分别从 Library、推荐和搜索选择漫画加入。对一个作者+标签过滤后点击“将全部筛选结果加入书架”，确认确认框数量与最终数量一致且超过当前可见页时仍完整。删除测试书架，确认漫画与下载仍在。

## C. 推荐 Session 与预览

依次查看 Session 1 的 1/5 到 5/5，再继续；必须进入 Session 2 而非回到旧 1/5。观察不重复，直到出现新 Session 或明确耗尽。打开一条推荐详情，预览默认只加载 3 页，“再加载”每次最多 3 页；关闭重开应命中缓存。设置中清理预览缓存。

## D. 单本 Pica 收藏（仅 capability 可用时）

挑选一部当前未收藏的测试漫画，先记下远端状态，再点击“加入 Pica 收藏”。在 Pica 账号中确认，随后同步 Favorites 并确认本地状态。不要在首次验收中批量改变远端收藏。

## E. Reader 与 CBZ

从“已下载”进入一部漫画，测试连续纵向、单页、双页、LTR/RTL、适应宽/高、全屏和键盘。切换到较后章节/页后关闭再打开，确认恢复。导出一个章节为 CBZ，用系统默认兼容阅读器打开，核对页序并确认压缩包不含凭据或本机路径。

## F. 回归

复核代理自动检测、Favorites 同步、网格/列表和 S/M/L、封面开关、实时下载进度、已下载页、Browser Lite 导出/导入/重新导入/推荐、单实例和干净退出。遇到问题请记录操作、页面、版本和脱敏日志；不要附账号、密码、token、Cookie 或代理凭据。
