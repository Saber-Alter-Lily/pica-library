Browser Lite

开始使用 Browser Lite

Browser Lite 使用从 Pica Library 导出的数据包，无需在网页中填写 Pica 账号或密码。

  1. 下载并打开 Pica Library Windows 版
  2. 完成首次设置并准备好漫画库
  3. 在“设置 → Browser Lite”中导出 Browser Lite 数据包
  4. 将生成的 pica-library-bundle.json 导入这里

完整数据包可包含已准备好的漫画库、作者信息和推荐结果。
